# Slyzzed Cybersecurity Portfolio

This site documents my practical work, technical development, and ongoing progression as a cybersecurity engineer.

I currently work within the cybersecurity industry and have developed a strong interest in digital forensics and incident response. My goal is to continue building the technical depth required to move further into DFIR-focused roles, particularly in areas such as incident investigation, evidence collection, endpoint analysis, security monitoring, and threat detection.

## Purpose of This Site

This portfolio serves as a record of the systems I build, the investigations I perform, and the lessons I learn through hands-on cybersecurity work.

Rather than presenting isolated exercises, I aim to document complete and repeatable workflows. This includes designing environments, implementing security controls, generating evidence, investigating suspicious activity, and reporting the final findings.

The site is intended to demonstrate:

- Practical cybersecurity engineering experience
- Digital forensics and incident response skills
- Security monitoring and detection engineering
- Homelab architecture and secure configuration
- Clear technical documentation
- Continued professional development

## Current Focus

My current focus is the development of a dedicated DFIR homelab that supports repeatable incident scenarios involving:

- Monitored Windows and Linux endpoints
- Attacker and victim systems
- Network segmentation and traffic control
- Centralised logging and security monitoring
- Endpoint and network evidence collection
- Structured forensic investigation
- Incident reporting and lessons learned

The environment is built around open-source tools where practical, with an emphasis on understanding how each component works rather than relying entirely on automated platforms.

## Portfolio Content
